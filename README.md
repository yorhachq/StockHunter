# StockHunter

> 把每一笔交易，变成可复盘、可解释、可持续优化的决策样本。

StockHunter 是一个面向个人投资者的交易记录与复盘系统，用来记录基金、股票、ETF 等资产的每一笔操作，计算动态持仓成本，沉淀交易理由，并基于你的历史行为与策略参数推演更合适的买入、卖出观察区间。

## 项目概览

StockHunter 不替代券商下单，也不试图直接给出“神奇答案”。

它更像一个属于你自己的交易决策工作台，用来解决三类长期问题：

- 记录问题：买过什么、卖过什么、为什么这样做
- 复盘问题：这次操作到底是纪律执行，还是临场情绪化决策
- 演进问题：后续买卖区间、仓位节奏和经验沉淀如何越来越清晰

## 核心能力

- 交易账本：记录买入、卖出、分红、送股等关键动作
- 成本分析：自动计算持仓数量、动态成本、已实现收益、浮动盈亏
- 价格快照：手工补录关键时点价格，构建价格与成本同屏对照
- 复盘档案：把交易原因、信心分、情绪标签和行动计划沉淀下来
- 决策辅助：根据成本线、波动率和仓位策略推演买入带与卖出带
- 组合总览：查看不同标的对总仓资金、收益和份额的贡献比例
- 图表交互：在价格波动线上直接标注买卖点，并支持鼠标悬浮查看详情
- 工具板块：内置基金卖出份额速算器，辅助按金额精确控制卖出仓位
- 演示数据：提供一键体验入口，便于快速理解系统完整工作流

## 页面模块

- 左侧边栏：组合概览、标的切换、资金占比与收益贡献概览
- 中央看板：价格带推演、仓位轨迹、交易账本、复盘时间线
- 右侧工作台：新增标的、录入交易、补录行情、追加复盘、工具面板

## 技术栈

- 前端：Next.js App Router + React 19 + TypeScript
- 样式：Tailwind CSS 4 + 自定义设计语言
- 数据库：SQLite，基于 Node.js 内置 `node:sqlite`，默认本地文件持久化
- 数据校验：Zod
- 脚本工具：tsx

## 架构与安全说明

### 它不是“纯前端静态站”

虽然页面界面由 React 渲染，但当前项目并不是把逻辑全部丢给浏览器执行的纯前端方案。

实际结构是：

- 浏览器负责界面展示、表单交互、图表悬浮提示与本地工具计算
- Next.js Server Actions 负责写入入口与表单提交编排
- 服务端领域层负责成本、仓位、收益、决策区间等核心计算
- SQLite 负责本地持久化存储

也就是说，这是一套 `Next.js + Server Actions + SQLite` 的本地优先单体应用。

### 为什么当前不拆独立后端服务

对于单用户、本地优先、强调快速记录和长期维护的交易工作台来说，单体架构有几个现实优势：

- 复杂度更低：不需要额外维护前后端两个仓库、网关、鉴权和接口契约
- 迭代更快：页面、提交逻辑、领域计算可以在同一处演进
- 部署更轻：本地即可运行，不依赖额外数据库或后端容器
- 可维护性更高：对单人使用工具而言，减少系统边界通常比“形式上的前后端分离”更重要

### 当前安全性保障

当前版本的安全边界定位是“单用户本地工具安全”，不是面向公网多租户 SaaS 的安全模型。

已具备的保障：

- 所有写操作都在服务端执行，浏览器不会直接接触数据库连接
- 表单输入经过浏览器约束、客户端即时提示、服务端 Zod 校验、服务端业务校验四层防护
- 卖出超持仓、快照高低价异常、分红/送股类型错填等脏数据会被服务端拒绝
- SQLite 默认本地文件持久化，数据不依赖第三方云数据库

当前版本尚未覆盖的公网级能力：

- 多用户认证鉴权
- 细粒度权限隔离
- CSRF 与审计日志体系
- 速率限制与输入审计
- 自动备份与敏感环境隔离

如果未来要部署到公网并支持多用户，这些能力需要作为单独阶段补齐。

## 目录结构

```text
src/
  app/                  路由、布局、Server Action
  components/           仪表盘、图表、表单组件
  config/               应用配置解析
  lib/db/               数据库初始化、Schema、仓储层
  lib/domain/           成本分析、格式化、领域类型
  lib/forms/            表单状态与共享校验规则
docs/                   需求说明与操作指南
scripts/                演示数据和重置脚本
```

## 快速开始

### 1. 安装依赖

```bash
pnpm install
```

### 2. 初始化配置

```bash
cp .env.example .env.local
```

### 3. 可选：写入演示数据

```bash
pnpm db:seed
```

### 4. 启动开发环境

```bash
pnpm dev
```

### 5. 访问系统

打开浏览器访问 [http://localhost:3000](http://localhost:3000)

## 常用命令

```bash
pnpm dev        # 本地开发
pnpm lint       # ESLint 校验
pnpm typecheck  # TypeScript 校验
pnpm build      # 生产构建
pnpm db:seed    # 写入演示数据
pnpm db:reset   # 清空数据库表
```

## 推荐使用顺序

1. 先创建标的，填好市场、币种和仓位策略参数
2. 回补历史交易流水，确保买入、卖出、分红记录完整
3. 补录关键价格快照，把主要拐点和当前参考价录进去
4. 在图上直接查看买卖点、价格线与成本线之间的关系
5. 使用份额速算器推演目标卖出金额对应的基金份额
6. 在关键决策后写复盘笔记，沉淀原因、情绪和下一步计划
